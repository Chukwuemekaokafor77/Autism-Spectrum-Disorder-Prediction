About the Model & Evaluation Metrics

This tool uses a logistic regression classifier trained on a published toddler ASD screening dataset (Q-CHAT-10, 2018). Features include 10 behavioral items plus age, sex, ethnicity, jaundice history, and family ASD history. The model was evaluated using stratified 80/20 split and 5-fold cross-validation.

Algorithm Logistic Regression
Training Set 843 records (80%)
Test Set 211 records (20%)
Features 15 (behavioral + demographic)
Validation 5-fold cross-validation
Accuracy 99.7%
