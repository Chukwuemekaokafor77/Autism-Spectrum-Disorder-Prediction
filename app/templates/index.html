About this model

This screening tool uses a logistic regression model trained on a published toddler ASD screening dataset. It is intended for educational and support purposes only.

Evaluation plots (confusion matrix and ROC curve) are generated by the training script and saved in the model/ folder as confusion_matrix.png and roc_curve.png.
